# MSPM0G3507 Workspace

This directory contains the MSPM0G3507 competition workspace.

## Directory layout

- `Projects/`: CCS projects and source code. Keep all project paths and names in English.
- `Resources/`: Local datasheets, drivers, vendor examples, videos, and hardware files. This directory is intentionally ignored by Git because it is large.

Create or import CCS projects under:

```text
MSPM0G3507/Projects/
```

Do not create CCS projects under `Resources/` or any path containing Chinese characters.

- CCStudio: `D:/TI/CCS`
- MSPM0 SDK: `D:/TI/SDK/mspm0_sdk_2_10_00_04`
- CCS projects: `D:/TI/Projects/elec-competition/MSPM0G3507/Projects`
