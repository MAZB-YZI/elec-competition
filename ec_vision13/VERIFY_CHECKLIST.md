# ec_vision 工具箱验证清单

> 目标:逐个确认 8 个模式都真能用,把参数 SV 存盘固化。
> 每项走完在 [ ] 打勾。用配套测试图(电脑全屏显示,相机对着拍)。
> 拍屏幕注意:稍远一点避免摩尔纹,屏幕调亮,别正对反光。

---

## 1. IDLE(相机调参)
- 操作:点 IDLE。底栏 `<` `>` 翻参数,`-` `+` 调值。
- 检查:
  - [ ] 画面正常、不发绿、不重影(exp_us 应为 0=自动)
  - [ ] 若发绿:确认 AWBloc=0;或微调 WB_R/WB_B
  - [ ] 调好后 SV 存盘
- 通过标准:画面清晰、颜色正常。

## 2. LINE(循迹)
- 测试图:`7_line_track.png`(黑线直线+弯道)
- 操作:点 LINE。红框=命中区域,绿线=拟合线。
- 检查:
  - [ ] 绿线贴合黑线,红框只框住黑线(不框背景)
  - [ ] err/ang 跟着线动(线居中时 err≈0)
  - [ ] 阴影干扰大时调大 AreaTh
  - [ ] SV 存盘
- 通过标准:绿线稳定贴合黑线,err 准确。

## 3. BLOB(色块)
- 测试图:`2_color_blocks.png`(红绿蓝三色块)
- 操作:点 BLOB → PICK → 框选红块 → 松手。
- 检查:
  - [ ] 取色后红框紧框红块,不误框绿/蓝/背景
  - [ ] 换框选绿块、蓝块,分别能锁定
  - [ ] c=(x,y) 输出色块中心
  - [ ] 每次取色后 SV 存盘(注意:一次只存一种色的阈值)
- 通过标准:框选哪个颜色就精准锁定哪个。

## 4. TARG(打靶-靶心)
- 测试图:`1_target_rings.png`(红色同心圆环)
- 操作:点 TARG → PickWhat 选 0(靶心)→ PICK 框选红环。
- 检查:
  - [ ] 绿十字标在圆心附近(激光红框现在会乱跳,是没激光笔,先忽略)
  - [ ] 靶心偏了可切换 method:改 params 里 target.method
        = "circle"(圆检测,最准) / "centroid"(质心) / "blob"(最大块)
  - [ ] SV 存盘
- 通过标准:绿十字稳定在圆心。激光部分等激光笔到。

## 5. DET(AI 识别)
- 前置:板上 /root/models/ 要有 .mud 模型文件
- 操作:点 DET。
- 检查:
  - [ ] 若显示 "model:xxx err" → 模型路径不对或没模型,记下来后面补
  - [ ] 有模型则:识别到物体画框+标签
- 通过标准:能加载模型并出框。**没模型则标记"待补模型",不阻塞其它。**

## 6. GIMB(云台)
- 前置:需要舵机接 A30(PWM6)/A31(PWM7),右排取 5V/GND
- 操作:点 GIMB。
- 检查:
  - [ ] 无舵机:显示 "gimbal:xxx err" 属正常,记下待硬件
  - [ ] 有舵机:云台把 BLOB 色块转向画面中心
- 通过标准:有舵机则追踪,无则标记"待硬件"。

## 7. CIRC(圆检测)
- 测试图:`3_single_circle.png`(单红圆)、`1_target_rings.png`
- 操作:点 CIRC。
- 检查:
  - [ ] 绿圈套住圆、中心画十字,c=(x,y) r=半径
  - [ ] 检测不到:调 CircTh(降)/ Rmin / Rmax(放宽半径范围)
  - [ ] SV 存盘
- 通过标准:绿圈准确套住圆,圆心稳定。

## 8. TAG(AprilTag)
- 测试图:`5_apriltag.png`(TAG36H11 id=0)
- 操作:点 TAG。tag 占画面大一点、别太斜。
- 检查:
  - [ ] 绿框框住 tag 四边,显示 id=0
  - [ ] 换 id 需重新生成图(当前只有 id=0)
- 通过标准:框住 tag 并正确显示 id。
